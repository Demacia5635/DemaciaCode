Demacia path follower

How a button press becomes swerve speeds in frc.demacia.path: waypoints become lines and corner arcs, then each 20 ms cycle follows the current segment.

Control flow

flowchart TD
    subgraph RC[RobotContainer]
        BTN[Controller left button] --> PTS[addPoints: hard-coded Pose2d list]
        PTS --> TRJ[new DemaciaTrajectory]
        BTN --> CMD[new FollowTrajectoryCommand]
    end

    subgraph BUILD[Build path: DemaciaTrajectory constructor]
        TRJ --> N{Number of waypoints}
        N -- "under 2" --> FIN0[Finished immediately]
        N -- "2" --> L1[Single LineSegment]
        N -- "3 or more" --> LINES[Raw LineSegment between each pair]
        LINES --> ARCS[CornerArcCalculator: one arc per inner waypoint]
        ARCS --> TAN[TangentCalculator: arc entry and exit poses]
        TAN --> SEGS[Line, Arc, Line, Arc, ..., Line]
    end

    subgraph CMDLIFE[FollowTrajectoryCommand]
        CMD --> INIT[initialize: reset odometry, trajectory.start]
        INIT --> EXEC[execute, every 20 ms]
        EXEC --> POSE[Read estimated pose and field-relative speeds]
        POSE --> CALC
        OUT[swerveCommand.setVelFieldRel] --> CH[Chassis drives]
        EXEC --> ISF{trajectory.isFinished?}
        ISF -- yes --> END[end: chassis.stop]
    end

    subgraph TRAJLOOP[DemaciaTrajectory.calculateChassisSpeeds]
        CALC[Get current segment] --> FOLLOW[SegmentFollower.calculateChassisSpeeds]
        FOLLOW --> DONE{Segment finished?}
        DONE -- no --> RET[Return speeds]
        DONE -- "yes, not last" --> NEXT[currentSegmentIndex++] --> RET
        DONE -- "yes, last" --> ROT{Heading within 5 degrees?}
        ROT -- yes --> FIN1[Trajectory finished, return 0, 0, 0]
        ROT -- no --> SPIN[Return 0, 0, omega only]
    end

    subgraph SF[SegmentFollower]
        FOLLOW --> TYPE{Segment type}
        TYPE -- Line --> LINEV[Trapezoid speed by distance to end. Heading mirrored across the line]
        TYPE -- Arc --> ARCV[Trapezoid speed by remaining arc length. Heading tangent plus look-ahead]
        LINEV --> OMEGA[Omega: ProfiledPID on heading error to segment end pose]
        ARCV --> OMEGA
        OMEGA --> RETSF[ChassisSpeeds vx, vy, omega]
    end

    RETSF --> RET
    RET --> OUT
    FIN1 --> OUT
    SPIN --> OUT

Proposed architecture

Solid arrows run every 20 ms. The dashed PathBuilder runs once, when the trajectory is created.

When a segment is finished

SegmentCondition
Last lineDistance to end is below FINAL_POINT_POSITION_THRESHOLD_METERS. The trajectory then also needs the heading within 5°.
Middle lineDistance to end is below MID_PATH_POSITION_THRESHOLD_METERS, or the end point has been passed (angle past MAX_ANGLE_TO_CONSIDER_POINT_PASSED_RAD).
ArcThe velocity heading is close to the exit tangent heading.
